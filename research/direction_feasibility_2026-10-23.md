## 4. 两次探针的教训怎么用上

1. **TRADING-2565-61、-62（整轮尺子）**：解析式按 t ≥ 2、当成每年独立来算，比探针高约 19 个点；名义 0.95 的区间误判 7–11%。这里：临界值取 t 的 0.995 分位（两侧 0.99），自由度取「独立单位 − 1」。横截面的独立单位是有效月数（扣掉月间自相关），事件的独立单位是财报季：同一季的事件算一个单位，季内相关已经折进季均值的方差。事件数由股票数定，不是随机次数；随机的是 AI 行情段数，见第 2 节最后一段。
2. **TRADING-2565-63、-64（长牛代价尺子）**：噪声假设漏了项，实际噪声是假设的 2.2–2.8 倍（定标 2.67 对 1.24；每段约 5 点对假设的 1.8 点，记分表第 3 节）。这里分两层：
   - 调整后：补上第 1 版漏的项。横截面：IC 的月间自相关 φ = 0.3（有效月数打 0.54 折），子行业扎堆让有效股票数降到 0.3 倍，IC 随时间的波动 τ 从 0.08 调到 0.12。事件：财报跳空的厚尾，20 日超额收益的标准差从 9% 调到 11%；同一季里 AI 产业链共享的叙事冲击，季内相关 ρ 从 0.02 调到 0.06。
   - 悲观：第 1 版的噪声标准差直接乘 2.5，取两次探针 2.2–2.8 倍的中间。
3. **把读数写成几项之和，看最大的一项**（`expected_template.md`「定标」）：
   - A1：每期 IC 的方差里抽样噪声（1/有效股票数）占 93%，τ 占 7%。17 只的瓶颈是股票数，不是 IC 的波动。
   - A2：抽样噪声 61%，τ 39%；月间自相关另外把有效月数打折。
   - B1：季均值的方差里季内相关那一项占 49%。
   - B2：季内相关那一项占 90%。股票再多也被同一季的共同冲击吃掉，ρ 是最该先量的数。

和第 1 版比：只把正态和 t ≥ 3 换成 t 和 0.99，补数据后的中等效果从 86%、75% 变成 93%、84%（临界值从 3 降到约 2.6）；再按教训调噪声，降到 41%、24%。结论变化全部来自噪声假设。

## 5. 方法

- 横截面：每期 IC 的标准差 = √(τ² + 1 / 有效股票数)；有效月数 = 12 × 年数 × (1 − φ) / (1 + φ)；非中心参数 = IC / 标准差 × √有效月数；自由度 = 有效月数 − 1。
- 事件：每季的季均值标准差 = √(σ² × (1 + (N − 1)ρ) / N)，N 是股票数；季数 = 4 × 年数；非中心参数 = μ / 季均值标准差 × √季数；自由度 = 季数 − 1。
- 检出率：P(非中心 t > t 的 0.995 分位)，按卡方分布数值积分，不用正态近似。只算判对方向的一侧。
- 测出后为真 = 先验 × 检出率 / (先验 × 检出率 + (1 − 先验) × 0.005)；测不出后为真 = 先验 × (1 − 检出率) / (先验 × (1 − 检出率) + (1 − 先验) × 0.995)。

## 附：计算

只用 numpy（项目 venv 里没有 scipy）。

```python
import math

import numpy as np

_erf = np.frompyfunc(math.erf, 1, 1)


def norm_cdf(x):
    return 0.5 * (1 + _erf(np.asarray(x) / math.sqrt(2)).astype(float))


def t_cdf(x, df):
    grid = np.linspace(0.0, abs(x), 20001)
    logc = math.lgamma((df + 1) / 2) - math.lgamma(df / 2) - 0.5 * math.log(df * math.pi)
    pdf = np.exp(logc - (df + 1) / 2 * np.log1p(grid**2 / df))
    return 0.5 + math.copysign(np.trapezoid(pdf, grid), x)


def t_crit(df, level=0.99):
    target, lo, hi = 1 - (1 - level) / 2, 0.0, 200.0
    for _ in range(80):
        mid = (lo + hi) / 2
        lo, hi = (mid, hi) if t_cdf(mid, df) < target else (lo, mid)
    return (lo + hi) / 2


def power(ncp, df, level=0.99):
    c = t_crit(df, level)
    u = np.linspace(1e-9, df + 40 * math.sqrt(2 * df) + 60, 40001)
    f = np.exp((df / 2 - 1) * np.log(u) - u / 2 - (df / 2) * math.log(2) - math.lgamma(df / 2))
    return float(np.trapezoid(f * norm_cdf(ncp - c * np.sqrt(u / df)), u) / np.trapezoid(f, u))


def cross_section(ic, n, years, tau, neff_ratio, phi=0.0, noise_mult=1.0):
    sd = math.sqrt(tau**2 + 1.0 / (n * neff_ratio)) * noise_mult
    t_eff = 12 * years * (1 - phi) / (1 + phi)
    return power(ic / sd * math.sqrt(t_eff), max(round(t_eff) - 1, 1))


def events(mu, n, years, sigma, rho, noise_mult=1.0):
    seasons = 4 * years
    season_sd = math.sqrt(sigma**2 * (1 + (n - 1) * rho) / n) * noise_mult
    return power(mu / season_sd * math.sqrt(seasons), max(round(seasons) - 1, 1))


# A2 补数据后、中等效果、调整后的噪声：约 0.409
print(cross_section(0.04, 150, 20, tau=0.12, neff_ratio=0.3, phi=0.3))
# B2 补数据后、中等效果、调整后的噪声：约 0.236
print(events(0.006, 150, 20, sigma=0.11, rho=0.06))
# A1 现有数据、中等效果、调整后的噪声：约 0.019
print(cross_section(0.04, 17, 5.7, tau=0.12, neff_ratio=0.3, phi=0.3))
```
