### 3.1 慢腿的回来条件（经典趋势，换实现）

> 规则（月底判，t+2 生效，没有记忆）：快腿 0.5 ×［21 日收益 ≥ 0］；慢腿 0.5 ×［21 日收益 ≥ 0，或 252 日收益 ≥ 0］。慢腿只在两个都 < 0 时出，21 日 ≥ 0 时一定在。敞口：21 日 ≥ 0 时 1；21 日 < 0、252 日 ≥ 0 时 0.5；两个都 < 0 时 0。

和月频 fast_slow（快腿 0.5 ×［21 日 ≥ 0］、慢腿 0.5 ×［252 日 ≥ 0］）比，四格里只有「21 日 ≥ 0、252 日 < 0」那一格不同：fast_slow 0.5，这条 1。下称 **R 月**：月底判出（21 日 ≥ 0、252 日 < 0）之后的那个持有月（t+2 生效起，到下次判定生效止）；差额是 0.5 × 该持有月的市场收益，不是判出 R 的那个月。

- 252 日 < 0 的时期里，敞口随快腿在 0 和 1 之间翻（fast_slow 是 0 和 0.5）。慢熊里反弹失败的月份这条规则吃整份，来回代价翻倍，换手变高。

### 3.2 状态表（只印，回答「先按基本面定趋势」）

口径：
- 三个序列都按评估台的 `monthly_known_at` 对齐，报告印每个序列用的滞后。CAPE 的价用当月月均价，月底已知；盈利按已有的 15 个月滞后取（方向保守）。

- 「段起点或之前为真」定成：段起点前 6 个月内（含起点那个月）有一个月为真。状态翻的月份对段起点的滞后，正负都印。
