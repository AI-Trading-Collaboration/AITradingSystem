# 预期模板（第 4 期起）

研究自动循环第 4 期章程（`charter_p4.md` 第 6 节）落地的预期写法，第二次横读（复盘线程，项目文件 `knowledge/claude/research-review/horizontal-read-2026-10-22.md` 第 1 节第 1、2、4、6 条）提的。出题的卡、试跑计划的预期注释、探针需求和正式题预注册的 `expected`，都按下面七列逐行写，写在任何一次运行之前。正式题的 C 区模板（`research/_template/prereg.yaml`）等下一次开正式题的批一起改。

| 列 | 写什么 |
|---|---|
| 读数 | 尺子要读的那个数，写成可检验的条件：方向和大小（「近 0」写成 \|r\| < 0.05；「同率」写成两族各 150 单元通过数之差 ≤ 3） |
| 预期（概率） | 成立或不成立，带概率；低于 0.5 即预期不成立 |
| 依据（按单元） | 按尺子要读的单元逐行列（每个慢熊段、快跌段、下跌段），每行写触发条件成不成立和引的数（写记录号），没数据写「无」；另一轨、另一把尺子的读数不进依据；没数据的单元过半时概率最高 0.6 |
| 代价构成 | 几何代价那行必填：代价 = 哪几项之和；趋势覆盖按「目标窗口的误报次数 × 每次错过的反弹」估，不抄别的窗口的年化数；长于 12 个月的段先算盈亏平衡 |
| 目标窗口像哪个已有窗口 | 在哪些可数特征上像（慢熊段数、V 型急跌数、利率方向）；两个已有窗口结论相反时写明像哪个 |
| 判法 | 从哪张表、哪一格读，满足什么算成立；跑之前写死，跑完不改 |
| 失败淘汰什么 | 这一行不成立时淘汰哪个解释（一句），和记分表「淘汰了哪个解释」一列对上 |

修订：任何一行的样本、窗口或口径改了，同一行重写概率和一句理由，并按单元重列依据；打包说明核对「改过的行有没有新概率」，没有就不发布。

压线和凭记忆的单元（第 5 期慢腿快回读完加，复盘线程项目文件 `knowledge/claude/research-review/p5-slow-leg-scorecard-columns-2026-10-23.md` 第 1 节第 1、2 行）：

- 估值正好压线、单元又是凭记忆时，概率写 0.5 并写「压线」，不往一边倒；要倒，依据里写出倒向哪边的那个单元。
- 按设计不能印的单元（例：慢腿快回的 R 月市场累计），预期按「段数 × 典型值」写成带子（例：中位 +6..+10），概率从线在带子里的位置算，不从一个点估算。
- 凭记忆写月收益的单元，一段的 D 离 0 在 5 点以内时这段算「不定」，不算「成立」，概率相应压低。
