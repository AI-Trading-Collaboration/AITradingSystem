# TRADING-2573 QQQ 非对称 VXN 波动门低倍择时杠杆开发窗口诊断（需求）

- 状态：`DONE`（开发窗口止损关闭，`kill_dev_screen`）。
- 性质：只读开发窗口的描述与止损诊断探针（B 区，位于 `src/ai_trading_system/research_probes/asym_vxn_leverage.py`），不读 2011 年以后任何数据，不进试验账本、不改研究门和尺子、不改日报、不碰券商。`production_effect=none`、`broker_action=none`。

## 1. 背景与与已有负结果的区别

2026-11-19 Owner 将投资目标定为“收益最大化，最大回撤不深于 QQQ 同期最大回撤”（`TRADING-2572`）。此前已测过两种直接杠杆做法：

1. `QQQ-Q1b`（A 级拒绝，`research/negative_results.md` 第 23 线）：单用 21 日已实现波动调杠杆，无趋势退出门，最高 3 倍（平均 2.34 倍），月底调仓，验证窗口每年跑输固定杠杆 7.0 个点。
2. `TRADING-2565-101` 杠杆账表与 `TRADING-2565-134` 三段同回撤总账表：将趋势降回撤信号（`F0001` 等）整体乘以常数 $L$（如 2 倍）。在 QQQ 1999–2010 上，$L$ 越大越差（主算在 $L=1$ 最高 +3.37 点/年，$L^*=2.18$ 降到 +1.19，稳健成本 −1.08）。

两者的结构性短板互补：`Q1b` 缺趋势退出且倍数过高；`F0001 × L` 缺波动率门，顶部高波转身期仍满格挂杠杆吃第一跌，且 $L=2$ 时额外波动拖累 $\frac{1}{2}L(L-1)\sigma_1^2$ 过大。

本探针测试一个机制上不同的组合：**双门解耦 + 不对称调仓 + 低倍上限（$L_{\max} \in \{1.3, 1.5\}$）**，且严格只在 **纯 QQQ + `VXN`** 上检验（遵循 2026-11-02 “QQQ 信号研究不用别的标的数据”规矩，不用美股大盘代理）。

## 3. 窗口、数据与临时基线参数

- **数据来源**：经 `qqq_long_history.load_daily` 读取已检查的长历史快照（`qqq_series="actual"`），在计算任何信号前经 `gate_power.cut` 机械截断至 `2010-12-31`。
- **评估窗口**：`2001-02-28` 收盘建仓（首日收益 `2001-03-01`）至 `2010-12-31`（因 `VXNCLS` 起始于 `2001-02-02`，取其后首个完整月末 `2001-02-28` 为共同起点，保证 `F0001` 与 `VXN` 均无预热缺口；同时在输入检查中核对 `2001-02-02..2010-12-31` 的 `vxn` 缺失数）。
- **执行滞后**：严格遵循评估台口径——收盘 $t$ 决定、收盘 $t+1$ 执行（首日计入收益为 $t+1 \to t+2$）；任何 `vxn` 缺失日一律保守按“不开杠杆（退回 `1.0`）”处理。
- **以下参数为本开发诊断的临时基线（退出条件：本次开发诊断完成并由 Owner 审阅止损判定后退出，不自动晋级或进入生产）**：
  - 底仓层：原样复用 `F0001`（21 日与 252 日 `ndx_return` 符号，月底调仓，敞口 $\in \{0, 0.5, 1.0\}$），不改参数；
  - 杠杆上限：$L_{\max} \in \{1.3, 1.5\}$；
  - `VXN` 滞回开关门（`asym_band`）：`VXN <= 20.0` 开启杠杆、`VXN >= 25.0` 撤回 `1.0`，区间 `(20.0, 25.0)` 保持状态；
  - `VXN` 公式反比平滑参照（`asym_invvol`）：底仓满仓时 $w = \text{clip}(25.0 / \text{VXN},\; 1.0,\; L_{\max})$，周频调仓死区 `0.10`（但回到 `1.0` 时不受死区阻挡，确保立刻去杠杆）；
  - 频率参照（`monthly_band`）：与 `asym_band` 完全相同的 `VXN` 滞回门，但杠杆层也改为月底调仓；
  - 融资与成本口径（方案 A）：
    - `main`：借钱部分年化利差 `1.0%`（相对 `DTB3`），单边换手成本 `4 bps`；
    - `robust`：借钱部分年化利差 `2.0%`，单边换手成本 `25 bps`；
    - `high_rate_5pct`：借钱部分固定按总年化利率 **`5.0%`** 计息（未借钱时现金仍按实际 `DTB3` 计息），换手成本 `4 bps`，用于模拟 2026 年高利率环境。

## 4. 对比矩阵、解剖表与止损线

### 4.1 固定对比配置（无参数网格搜索）
- 基准组：`hold`（100% QQQ）、`f0001_1.0`（1 倍 `F0001`）、`f0001_1.3` / `f0001_1.5`（无 `VXN` 门纯趋势放大）。
- 新机制组：`asym_band_1.3`、`asym_band_1.5`（主测）；`asym_invvol_1.3`、`asym_invvol_1.5`（平滑参照）；`monthly_band_1.3`、`monthly_band_1.5`（月频参照）。

### 4.2 解剖表（每条线强制输出）
1. 几何年化、算术年化、年化波动、最大回撤、超额夏普（扣 `DTB3`）、超额卡玛；
2. 对 `hold` 与对 `f0001_1.0` 的几何年化差（`main` / `robust` / `high_rate_5pct`）；
3. 拖累拆账（年化对数点）：算术收益、波动拖累 $\frac{1}{2}\sigma^2$（及相对 1 倍的额外波动拖累）、融资利息拖累、换手成本拖累；
4. 行为与危机分段诊断（2001-03..2002-10 泡沫尾段、2002-11..2007-10 长牛、2007-11..2009-03 金融危机、2009-04..2010-12 反弹）：杠杆开启天数占比、平均借钱比例 $\bar{b}$、周频去杠杆触发次数、进入危机段首个交易日杠杆是否已退回 `<= 1.0`。

### 4.3 开发窗口止损线（Kill Criteria）
对主测配置（`asym_band_1.3` 或 `asym_band_1.5`），在 `2001-02-28..2010-12-31` 开发窗口必须**同时**满足以下 4 条，才判定 `pass_dev_screen`（有资格进入后续是否预注册正式题的讨论）；否则判 `kill_dev_screen`，直接止损不调参、不读验证窗口：
1. `main` 最大回撤浅于或等于 `hold`；
2. `main` 几何年化超过 `hold` 至少 `+1.0` 点/年，且 `robust` 几何年化不低于 `hold`；
3. `main` 与 `high_rate_5pct` 几何年化均严格高于 `f0001_1.0`；
4. 同 $L_{\max}$ 下，`main` 几何年化高于无波动门对照 `f0001_L`，**或**最大回撤浅于 `f0001_L` 至少 `1.0` 个点且几何年化不低于 `f0001_L` 超过 `0.5` 点。

  - **核心归因（结构性机制失灵，而非参数巧合）**：
    1. 周频 `VXN` 不对称去杠杆确实有效压住了 2008 危机入场回撤（2007-11 入场时已去杠杆，危机最大回撤 −27.45% vs 无波动门 −34.32%/−38.86%）。
    2. 但“低 `VXN` 开杠杆、高 `VXN` 去杠杆”天然制造了**高位加杠杆、低位去杠杆的反向择时**：牛市最肥的反弹期（2003、2009）`VXN` 偏高导致门关闭、错失杠杆收益；等到牛市中后期涨高、`VXN ≤ 20` 才加到 1.3x–1.5x，随即在 2002–07 慢牛回调里吃满杠杆下跌（慢牛最大回撤 −28.73% vs 1x −17.77%），跌到 `VXN ≥ 25` 才在短期低位退回 1.0x。
    3. 临时基线参数按第 3 节退出条件于 2026-11-22 经 Owner 审阅确认止损关闭并发布入库，不调参、不读验证窗口。
