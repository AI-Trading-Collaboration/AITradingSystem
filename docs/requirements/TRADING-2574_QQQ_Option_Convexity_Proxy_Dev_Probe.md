## 1. 背景、分工与与已有负结果的区别

1. **与 `TRADING-2567-20/21`（负结果第 19 线）的区别**：此前只测了**卖波动**（现金担保平值卖 Put / Covered Call），结论是卖波动靠波动率溢价抬高年化，但负 Gamma 导致回撤和左尾大幅恶化（−38.8% 对 −29.4%），被收掉。本探针测相反方向：**买正凸性（Long Convexity）**——下跌时 Delta 自动滑向 0 截断深跌，V 型急弹时 Delta 自动爬回 1 避免踏空。
2. **与 `TRADING-2567-41`（`owner_decision:TRADING-2567:2026-11-22:option_index_first_look`）的分工互补**：`TRADING-2567-41` 用 2009 起的免费纳指期权指数看 `BXN`（月度备兑）、`NQTRI`（季度 90% 保护 Put）、`NQCLRI`（季度 95–110 领口）在 2011–2026 的表现；本探针零成本补齐两大盲区：
   - **结构盲区**：测试三条指数未覆盖的 **「现金 + 滚动 3M/6M Call（Stock Replacement 正凸性替代）」** 及 **无融资自资金按回撤配平名义倍数 $L^*$**；
   - **时间盲区**：在 **`2001-02-28..2010-12-31`** 完整覆盖 2009+ 指数看不到的 **2001–02 泡沫尾段**与 **2008 金融危机**。
3. **与 `TRADING-2573` 的衔接**：`TRADING-2573` 证伪了用低 `VXN` 指导现货加杠杆（在牛市形成高位加杠杆、低位去杠杆）。本探针检验用期权内在正凸性自动调 Delta 是否能绕开择时踏反陷阱，以及所付隐含波动率溢价（`VXN − RV`）是否低于现货择时代价。

## 3. 窗口、定价假设与临时基线参数

- **数据来源**：经 `qqq_long_history.load_daily` 读取已检查的长历史快照（`qqq_series="actual"`），计算前经 `gate_power.cut` 机械截断至 `2010-12-31`。

- **定价与局限（明确披露，非可交易真实成交）**：无分红 Black-Scholes、用 `sigma_scale * VXN` 作波动率、无买卖价差、无波动率偏度（Skew）、无提前行权与手续费。为避免低估买方成本，固定测试三档缩放：`sigma_scale ∈ {0.9, 1.0, 1.1}`，其中 `1.0` 为基准，**`1.1` 模拟买方吃 `ask` 价差与偏度惩罚的悲观情景**。
- **以下参数为本次开发诊断临时基线（退出条件：本次开发诊断完成并由 Owner 审阅止损判定后退出）**：
  - 基准组：`hold`（100% QQQ）、`f0001_1.0`（1 倍 `F0001` 现货趋势标杆）；
  - 核心正凸性 Call 替代组：
    - `call_3m_atm`：每 3 个月末展期买 100% 名义 ATM Call（$K = 1.00$），余款拿 `DTB3`；
    - `call_6m_atm`：每 6 个月末展期买 100% 名义 ATM Call（$K = 1.00$），余款拿 `DTB3`；
    - `call_6m_itm85`：每 6 个月末展期买 100% 名义 85% 实值 Call（$K = 0.85$），余款拿 `DTB3`；
  - 保护性现货叠加对照（对应 `NQTRI` / `NQCLRI` 的 2001–2010 代理）：
    - `put90_3m`：每 3 个月末自融资持 QQQ + 90% 保护性 Put（$K = 0.90$）；
    - `collar_95_110_3m`：每 3 个月末自融资持 QQQ + 买 95% Put − 卖 110% Call。
  - **同回撤配平名义倍数 $L^*$**（网格 `1.00..3.00` 步长 `0.05`）：
    - 对 Call 替代组：当 $L \cdot c_0 \le 1.0$ 时完全自融资（无需借钱，余款 $(1 - L c_0)$ 仍拿 `DTB3`），若超过 1.0 则超出部分按 `DTB3 + 1%` 计息；
    - 对 Put / Collar 组：组合整体按 `DTB3 + 1%` 保证金口径缩放。
    - 寻找最大 $L^*$ 使最大回撤不深于同期 `hold`。

## 4. 解剖表与开发窗口止损线（Kill Criteria）

### 4.1 必看解剖账
每条结构按 `sigma_scale = 1.0`（并附 `0.9` / `1.1` 敏感度）输出：
1. 1.0x 名义与同回撤配平 $L^*$ 下的几何年化、对 `hold` / `f0001_1.0` 差值、最大回撤、年化波动、超额夏普、超额卡玛；
2. **Delta 副本拆账**：`期权净年化 − 每日动态 Delta 现货副本年化`（正凸性 Gamma 净盈利减波动率保费）与 `Delta 副本年化 − 同平均敞口固定混合年化`（自动动态调仓价值）；
3. 每周期平均权利金、`VXN` 相对周期实现波动溢价（`IV − RV`），以及四个危机/慢牛分段（2001–02、2002–07、2007–09、2009–10）表现。

### 4.2 开发窗口止损线
对任意主测期权结构（`call_3m_atm`、`call_6m_atm`、`call_6m_itm85`、`put90_3m`、`collar_95_110_3m`），在 `2001-02-28..2010-12-31` 开发窗口必须**同时**满足以下 3 条，才判定 `pass_dev_screen`（值得讨论下一步用真实 `bid/ask` 数据核实）；否则判 `kill_dev_screen`，直接证伪收题，不买付费期权数据：
1. `sigma_scale = 1.0` 下，1.0x 名义或同回撤配平 $L^*$ 的最大回撤浅于或等于 `hold`；
2. `sigma_scale = 1.0` 下，上述配置几何年化超过 `hold` 至少 `+1.0` 点/年，**且**高于现货择时标杆 `f0001_1.0`；
3. 买方悲观定价 `sigma_scale = 1.1` 下，同配置几何年化仍不低于 `hold`（且对 `f0001_1.0` 差距不超过 `0.5` 点）。
